# FAQ

## Is RouterHub an OpenRouter alternative?

Yes, it can be used as one. RouterHub is a separate prepaid API gateway. It is not affiliated with OpenRouter.

## Is RouterHub better than OpenRouter?

Not universally. RouterHub is simpler for prepaid access and explicit uncensored/abliterated entries. OpenRouter may be better for its specific routing and marketplace features.

## Can I use my OpenRouter API key?

No. Create a RouterHub account and use a RouterHub key.

## Can I use my OpenRouter model ID?

No. Use the exact RouterHub model ID from the catalogue.

## Does RouterHub support the OpenAI SDK?

Yes, for OpenAI-compatible entries. Set the base URL and key.

## Does RouterHub support Anthropic SDK / Claude Code?

Only for entries that support Anthropic Messages. Confirm in the catalogue.

## Does RouterHub offer uncensored models?

Yes, where listed. Examples include `deepseek-v4.1-flash-uncensored`, `glm-5.3-uncensored` and `qwen3.8-max-uncensored`.

## Does RouterHub offer abliterated models?

Yes, where listed. Examples include `deepseek-v4.1-flash-abliterated` and `glm-5.3-flash-abliterated`.

## How is billing handled?

Prepaid, pay per token. Card and crypto top-ups. No subscription.

## Are prices guaranteed?

No. Prices and availability can change. Check the live catalogue.

## Can I migrate gradually?

Yes. Send a small share of traffic first, compare quality and cost, then increase.

## Does this repository guarantee ranking?

No. It is a comparison and SEO resource; rankings depend on many factors.
