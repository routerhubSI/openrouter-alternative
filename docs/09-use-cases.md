# Use Cases

## Coding agents

Use a coding-capable model through one key and compare standard vs uncensored/abliterated entries for agent loops. Confirm tool-call support before deploying.

## Research and evaluation

Compare model families and variants on the same prompts. Keep the exact model ID in your test records.

## Writing and editing

Use uncensored or abliterated entries where the standard model interrupts legitimate creative work. Keep style and quality checks in place.

## Bilingual products

Route Chinese/English workloads through the same account and measure quality on real prompts.

## Cost-sensitive batch jobs

Use prepaid, pay-per-token billing and compare cost per successful task, including retries.

## Prototyping an OpenRouter migration

Test RouterHub with a small share of traffic before moving production. Verify model IDs, protocols, response shapes and fallbacks.

## What not to use it for

- Illegal activity
- Harassment, fraud or malware
- Bypassing security controls
- Safety-critical decisions without human review
