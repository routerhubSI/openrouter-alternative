# Safety

A reduced-refusal model is a tool, not a permission slip.

## Lawful use

Use RouterHub and its model providers for lawful purposes. Do not use uncensored or abliterated entries for illegal content, harassment, fraud, malware or bypassing security controls.

## Provider terms

RouterHub and upstream model providers have their own terms. Using a gateway does not override them.

## Guardrails

- Input filtering for prohibited content.
- Output checks for unsafe code or policy violations.
- Tool allowlists and human approval for irreversible actions.
- Budgets and rate limits per key.
- Logging for incident review.

## Data

Do not send secrets, credentials or unnecessary personal data. Use separate keys or budgets for projects.

## Evaluate before deploying

Test refusal behavior, quality, tool use and cost. Re-test after model updates.
