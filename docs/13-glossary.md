# Glossary

**Abliterated** — Weights modified to reduce a model’s refusal direction.

**API gateway** — A service that routes requests to model providers and handles auth, billing and model selection.

**Base URL** — Root URL for API requests.

**Cached input** — Input tokens served from a prompt cache, often cheaper.

**Chat Completions** — OpenAI-style `/chat/completions` format.

**Claude Code** — Anthropic’s coding client; requires a Messages-compatible entry where applicable.

**Model ID** — Exact identifier sent in the `model` field.

**OpenRouter** — A separate model routing/marketplace platform. Not affiliated with RouterHub.

**OpenRouter alternative** — Another gateway or API service used instead of OpenRouter.

**Pay per token** — Billing based on input/output/cached tokens; no subscription.

**Protocol** — The request/response format a model supports: Chat Completions, Anthropic Messages or Responses.

**RouterHub** — The prepaid AI API gateway documented here.

**Uncensored** — A model that refuses less often; method varies.
